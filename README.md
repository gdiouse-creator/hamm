# hamm
狂記帳 · 功能說明 · 完全免費 · Ger設計
一、記帳
四種紀錄類型：支出／收入／轉帳／校正
支出、收入：選類別（兩層：大類＋子類別）、選錢包（兩層：類型＋明細）
轉帳：選「轉出」「轉入」兩個錢包，不計入收支統計
校正：實際盤點後（例如查銀行 App、數現金）跟系統算出來的對不上，直接輸入「現在實際金額」，系統自動記一筆差額，不計入收支統計，但會留下紀錄
選任一欄位時，下方即時顯示該錢包「目前餘額」
支援多國貨幣，選外幣時即時顯示換算後新台幣金額
內建小算盤，金額欄位可直接按算式
類別／錢包若清單裡沒有，可用「＋」直接新增，不用跳頁
二、統計（儀表板）
目前資產：即時計算（起始值＋所有交易），不是手動維護的死數字，可點擊篩選看該錢包的相關紀錄
月份切換：可切換查看任何一個月的統計，不限於本月
本月收支：該月收入／支出／結餘
本月分類統計：手風琴形式，可展開看子類別明細，可直接在此新增子類別、點擊篩選跳轉到總表
收支趨勢圖：日／週／月／年四種粒度 × 綜合／收入／支出三種模式，圖表下方附文字數據表
分類細分：長條圖顯示，支出／收入／收支綜合／各錢包 四種角度，第一層／第二層可切換
三、總表
所有紀錄（含轉帳、校正）依時間排序
每筆紀錄顯示「異動前 → 異動後」的錢包餘額
可篩選（從統計頁點擊分類或錢包跳轉過來）
可編輯、可刪除
四、設定
支出類別／收入類別：新增、刪除子類別（刪除後舊紀錄自動歸回上層類別，不會遺失）；第一層類別只能改名、不能刪除，避免歷史紀錄找不到歸屬
錢包結構：新增、改名、刪除錢包類型與明細
貨幣與匯率：輸入國家名／貨幣名／三碼代號皆可辨識（涵蓋約 80 個國家地區），連網自動更新匯率，也可手動輸入
外觀配色：4 組預設配色，或自訂 8 種顏色（背景、邊框、文字、圖表色等）
類別／錢包項目都可設定專屬 emoji 圖示
五、資料與備份
資料存在本機裝置（IndexedDB），不經過雲端，離線也能記帳
匯出：JSON（完整備份，含設定）或 CSV（可用 Excel 開啟編輯）
匯入：對應匯出的兩種格式，CSV 自動辨識編碼與分隔符號
匯出提醒：可設定 3／5／7／30 天，超過天數開啟頁面會提醒，提醒視窗可直接匯出或略過
換裝置、資料轉移都靠「匯出→匯入」手動進行，不會自動跨裝置同步
六、App 化
可加到手機主畫面，全螢幕使用（PWA）
離線可開啟（service worker 快取），連上網會自動抓最新版本
自訂開場動畫與圖示
七、其他
所有金額換算鎖定「記帳當下」的匯率，之後匯率更新不會讓舊紀錄跟著變動
系統內部所有日期計算皆以裝置本地時區為準
